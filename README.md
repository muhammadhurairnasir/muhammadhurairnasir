## 🚀 About Me

I'm a Computer Science student at COMSATS University Islamabad (Lahore Campus) and an Associate Software Engineer building full-stack, production-facing software. My core stack is **React.js / Next.js, Node.js, Express.js, and MongoDB**, paired with **SQL Server** for relational, schema-heavy systems.

What sets my work apart is that it doesn't stop at "demo-ready." **Lumina**, my e-commerce platform, is live in production at [thelumina.shop](https://thelumina.shop) — with real Stripe payment webhooks, role-based authentication, and an AI-driven inventory forecasting module built on the Anthropic Claude API. I've had to debug real production issues, from payment webhook edge cases to chatbot intent-matching failures, and take ownership of the fixes.

Alongside full-stack development, I've built systems that lean into **AI and NLP** — an audio-to-insight meeting intelligence pipeline (Whisper + BART + spaCy), a custom NLP intent-matching chatbot built without third-party bot libraries, and a computer vision app for plant disease detection. I'm also building backend depth in **C# and ASP.NET Core** through self-directed study on top of my Compiler Construction coursework.

## 💡 What I Do

- 🌐 Build and ship full-stack web applications using **React.js / Next.js, Node.js, and Express.js**
- 🗄️ Design relational and NoSQL data models — normalized **SQL Server** schemas and **MongoDB** document stores
- 💳 Implement production-grade payment flows with **Stripe**, including webhook verification
- 🔐 Build **JWT-based, role-aware authentication** across multiple user types
- 🤖 Integrate LLM APIs (Anthropic Claude) into real product features like demand forecasting
- 🧠 Build NLP pipelines — intent matching, transcription, summarization, and entity extraction
- 👁️ Connect trained computer vision models to REST APIs for mobile clients
- ⚙️ Set up CI/CD pipelines with **GitHub Actions** and deploy to platforms like **Railway**
- 🤝 Collaborate in Agile teams using Git feature branching and structured code review

A production e-commerce platform built with MVC architecture and deployed live.

## 🧭 Development Philosophy

I take full accountability for what I ship. On Lumina, that has meant going past "it works on my machine" and actually resolving real production issues — payment webhook failures, chatbot intent-matching edge cases — through critical analysis rather than guesswork. I lean on OOP and clean architecture to keep systems maintainable as they grow, whether that's a normalized SQL Server schema for a restaurant system or a Flask dashboard behind an NLP pipeline.

I also treat unfamiliar technology as a solvable problem, not a blocker: I picked up Visual Studio and C# through Compiler Construction coursework, then chose to keep building on that with self-directed ASP.NET Core study — pairing it with the MERN stack I already work in daily.
