## About Me

I'm a Computer Science student at COMSATS University Islamabad (Lahore Campus) and an Associate Software Engineer building full-stack, production-facing software. My core stack is **React.js / Next.js, Node.js, Express.js, and MongoDB**, paired with **SQL Server** for relational, schema-heavy systems.

What sets my work apart is that it doesn't stop at "demo-ready." **Lumina**, my e-commerce platform, is live in production at [thelumina.shop](https://thelumina.shop) — with real Stripe payment webhooks, role-based authentication, and an AI-driven inventory forecasting module built on the Anthropic Claude API. I've had to debug real production issues, from payment webhook edge cases to chatbot intent-matching failures, and take ownership of the fixes.

Alongside full-stack development, I've built systems that lean into **AI and NLP** — an audio-to-insight meeting intelligence pipeline (Whisper + BART + spaCy), a custom NLP intent-matching chatbot built without third-party bot libraries, and a computer vision app for plant disease detection. I'm also building backend depth in **C# and ASP.NET Core** through self-directed study on top of my Compiler Construction coursework.
